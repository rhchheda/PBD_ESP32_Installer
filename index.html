This tool sets up your machine for embedded development in one run. It installs the Arduino IDE, the ESP32 board support you need for the DOIT ESP32 DEVKIT V1, and the USB drivers (CP210x and CH210x) that let your computer talk to the board over a cable. You run one file, approve a couple of prompts, and it handles the rest.

Before you start

  • Windows 10/11 or macOS, with your machine's admin password on hand
  • About 3 GB of free disk space
  • A stable internet connection (downloads run in the background)
  • Your ESP32 DOIT DEVKIT V1 board and USB cable, for after setup finishes

Windows setup

  1. Download the setup folder and double-click Run-Setup.bat.
  2. A dark command window opens briefly, then a User Account Control prompt appears. Click Yes.
  3. Windows may show a blue "Windows protected your PC" screen. This is expected for a new institute tool. Click More info, then Run anyway.
  4. A progress dashboard opens and works through each step on its own. This takes a few minutes depending on your internet speed.
  5. When it finishes, a result window tells you setup is complete. Click OK and plug in your board.
Why the warning appears: this installer is not yet signed with a paid publisher certificate, so Windows flags any new, unrecognized tool this way. It does not mean the file is unsafe, only that Windows does not yet recognize the publisher.

Mac setup

  1. Download the setup folder and locate Install-Project-Clinic-Setup-Mac.command.
  2. Right-click (or Control-click) the file and choose Open, rather than double-clicking it the first time.
  3. macOS will warn that the file is from an unidentified developer. Click Open again to confirm.
  4. Enter your Mac password when asked. This is needed to install drivers.
  5. Notifications will appear in the top right corner as each step completes. Setup finishes with a summary dialog.

If something goes wrong

Every run writes a log file you can share with your instructor:

Windows:
%TEMP%\ee-lab-setup\install-log.txt

Mac:
/tmp/ee-lab-setup/install-log.txt

Most issues are one of two things: not enough free disk space, or a slow/interrupted internet connection during download. Re-running the setup file is safe. It reuses anything already downloaded and only redoes what is missing.

Need help

Reach out to your lab instructor or the Project Clinic team at C-SHInE with the log file above, and mention which step the dashboard was on when it stopped.
